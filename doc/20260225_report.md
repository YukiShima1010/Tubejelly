# TubeJelly 機能追加レポート

**日時:** 2026-02-25 12:52 JST

---

## 実装内容

### 1. マルチユーザー対応

Discord User IDごとに異なるダウンロードディレクトリを指定できるようになりました。

**新規ファイル:**

- `src/config/users.json` — ユーザーID → ディレクトリのマッピング設定
- `src/utils/userConfig.ts` — ユーザー設定読込ユーティリティ

**変更ファイル:**

- `src/utils/download.ts` — `downloadAsMP3`, `downloadPlaylist` に `basePath` パラメータ追加
- `src/utils/fileManager.ts` — `getAllMusicFiles`, `getMusicFileByIndex` に `basePath` パラメータ追加
- `src/index.ts` — 起動時にユーザー設定をロードし、各ユーザーのディレクトリを確認
- `src/commands/add.ts` — ユーザー認証チェック + ユーザー別ディレクトリ使用
- `src/commands/addList.ts` — 同上
- `src/commands/list.ts` — 同上
- `src/commands/delete.ts` — 同上
- `src/commands/edit.ts` — 同上
- `package.json` — build スクリプトに config ファイルのコピーを追加

**使い方:**

`src/config/users.json` にDiscord User IDとディレクトリを設定します：

```json
{
  "123456789012345678": "/music",
  "987654321098765432": "/music2"
}
```

未登録ユーザーがコマンドを実行した場合、エラーメッセージが表示されます。

---

### 2. addlistコマンドにアーティスト名オプション追加

`/add_list` コマンドに `artist` オプションを追加しました。プレイリスト内のすべての曲に同じアーティスト名が適用されます。

**使用例:**

```
/add_list url:https://youtube.com/playlist?list=xxx artist:歌手A album:ベストアルバム
```

---

### 3. アーティスト一覧＆一括変更コマンド

**新規ファイル:**

- `src/commands/artists.ts` — `/artists` コマンド

**サブコマンド:**

#### `/artists list`

ライブラリ内のすべてのアーティストを曲数付きで一覧表示します。

#### `/artists rename old:<旧名> new:<新名>`

指定したアーティスト名を持つすべての曲のアーティスト名を一括変更します。ID3タグの更新とファイルの再配置（アーティスト/アルバム/曲名.mp3）を行います。

**使用例:**

```
/artists list
/artists rename old:チャンネル名 new:正しいアーティスト名
```

## 注意事項

- `src/config/users.json` に実際のDiscord User IDを設定する必要があります
- Docker Composeで複数ユーザーのディレクトリを使用する場合、`docker-compose.yml` に追加のボリュームマウントが必要です
- `@eslint/js` パッケージを `devDependencies` に追加しました（既存のeslint設定で必要だったため）
